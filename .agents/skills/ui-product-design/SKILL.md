# UI Product Design

Use this skill whenever working on user-facing interfaces.

## Goals

- Optimize for clarity, readability, and polish
- Prefer product-quality UI over developer-centric UI
- Reduce visual clutter
- Use strong hierarchy and consistent spacing
- Make labels readable at a glance
- Avoid tiny text and cramped controls
- Prefer guided flows over exposing low-level complexity
- Validate visually with screenshots whenever possible

## Rules

- Review existing UI before changing it
- Reuse design system components where possible
- Favor structured layouts over raw freeform canvases unless explicitly required
- For builder/configurator UIs, prioritize ease of use and visual coherence
- If a UI element feels “technical” but not useful to the user, de-emphasize or hide it
- After implementation, do a screenshot-based review and polish pass

## Anti-patterns

- tiny unreadable labels
- overly dense grids
- awkward image sizing
- misaligned controls
- spacing inconsistencies
- exposing internal data-model complexity as first-class UI
